# Contributing

Small, useful improvements are welcome. For a change to the data model or persistence behavior, open an issue describing the use case before implementation.

1. Run the app with `npm start`.
2. Make the smallest change that solves the problem.
3. Run `npm test` and `npm run check`. For UI or persistence changes, also follow `docs/TESTING.md`.
4. Describe the user-visible behavior and the checks you performed in the pull request.

Use fictional sessions in examples, screenshots, issues, and tests. Do not publish anyone's actual training notes, contact details, or health information. Keep dependencies and outbound network requests out of the app unless the change has been discussed first.

Potential starter tasks are optional session tags, comparing training periods, and broader accessibility review. Roadmap items are proposals; a contribution should implement and verify something useful rather than generate activity for its own sake.
